# An h1 header

Paragraphs are separated by a blank line. _Italic_, **bold**, and `inline code`.

Use 3 dashes for an em-dash — or 2 dashes for ranges (chapters 12--14).

## An h2 header

- this one
- that one
- the other one

Here's a numbered list:

1. first item

3. third item

> Block quotes are written like so.
>
> They can span multiple paragraphs, if you like.

Here is a code block:

```python
import time

# Quick, count to ten!
for i in range(10):
    time.sleep(0.5)
    print(i)
```
